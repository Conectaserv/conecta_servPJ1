Conecta Serv
Plataforma web desenvolvida para conectar empresas e freelancers de forma prática, rápida e segura.
O sistema permite divulgação de serviços, contratação de profissionais, gerenciamento de propostas e comunicação entre usuários em um ambiente moderno e intuitivo.
🚀 Funcionalidades
Cadastro e login de usuários
Cadastro de empresas e freelancers
Publicação de serviços
Sistema de propostas
Chat entre empresa e freelancer
Avaliação de profissionais e empresas
Página de serviços aceitos
Gerenciamento de perfil
Banco de dados integrado
Interface responsiva para desktop e mobile
🛠️ Tecnologias Utilizadas
Frontend: HTML, CSS, JavaScript
Backend: Node.js
Banco de Dados: MongoDB / MySQL (ajuste conforme estiver usando)
Hospedagem: Render
📱 Compatibilidade
A plataforma foi desenvolvida para funcionar em:
Computadores
Tablets
Smartphones Android
Smartphones iPhone
🎯 Objetivo do Projeto
O Conecta Serv foi criado com o objetivo de facilitar a conexão entre empresas e profissionais freelancers, oferecendo uma plataforma simples, eficiente e acessível para contratação de serviços.
🔒 Segurança
O sistema conta com:
Autenticação de usuários
Proteção de rotas
Gerenciamento de sessões
Privacidade de dados
Controle de acesso

Bash

npm start
