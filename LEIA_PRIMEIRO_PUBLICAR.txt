----------------------------------------

  1. https://dashboard.render.com  (login com GitHub)
  2. New + -> Web Service -> escolha "conectaserv"
  3. Cole estes valores:

     Build Command:
     pip install -r requirements.txt

     Start Command:
     gunicorn --bind 0.0.0.0:$PORT wsgi:application

     Plan: Free

  4. Environment Variables -> Add:

     SECRET_KEY = (cole a chave abaixo)
     FLASK_ENV = production
     PYTHON_VERSION = 3.11.0

  Gere SECRET_KEY no PowerShell:
  python -c "import secrets; print(secrets.token_hex(32))"

  5. Create Web Service -> aguarde Live -> abra a URL
